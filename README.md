
Mi pagina de musicStream

Hola
Esta es mi página web de música que estoy armando, pa’ mostrar artistas, álbumes y todo lo que tenga que ver con la música que me gusta. La hice con puro HTML y CSS, sin complicarme con JavaScript todavía.

Qué tiene la página

Inicio: Pa’ ver lo más reciente y las cosas principales.  
-Artistas Una sección con los artistas que me laten.  
-Álbumes:Todos los discos que quiero mostrar.  

-Contacto Para que me escriban si quieren hablar o colaborar.  
-Estadísticas (opcional):Cosas visuales pa’ mostrar datos de música.

Cómo usarla

1. Abrí el archivo index.html en cualquier navegador.  
2. Navegá por las secciones con el menú.  
3. Todo está conectado y listo, nomás faltan tus datos o imágenes si querés cambiarlo.

Notas

-Esta página es solo de práctica, pero se ve bien chiva 
-Todo es puro HTML y CSS, así que funciona en cualquier navegador moderno.  
-Si querés meterle más cosas después, se puede ampliar sin broncas.
